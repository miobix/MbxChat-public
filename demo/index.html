MbxChat recorded demo

A Telegram bot for practising written Korean, built as a LangGraph agent. These are replays of conversations recorded from the real bot code. Nothing here calls a model.

Pick an input. Each one plays once; ↻ Reset brings them back.

What a replay leaves out:

  • your own input: every message and tap was scripted, and every reply was recorded once from the local model named above,
  • example sentences from the user's MbxRead reading library (off when recording),
  • Anki: cards were queued because Anki was closed,
  • the runs that failed: each input was recorded once and kept only if it passed automatic checks (no error, the word found in krdict, a planted slip caught, a clean answer not flagged, no note praising an answer it marked down) and a read-through for wrong Korean or contradictions. The others are not shown; how many is in the line under the chat.
