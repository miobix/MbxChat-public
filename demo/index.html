Notes

Recorded from the real bot code. Nothing here calls a model.

Runs that failed are not shown. A run was kept only if it passed automatic checks (no error, the word found in krdict, a planted slip caught, a clean answer not flagged, no note praising an answer it marked down) and a read-through for wrong Korean or contradictions.
